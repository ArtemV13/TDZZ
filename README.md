# Сайт ТД «Зерно Заволжья» — tdzz.ru (v19)

Статический сайт (RU + EN) + небольшой PHP-бэкенд для форм и редактора цен.
Собран заново из прототипа v18: один шаблон для всех страниц, один CSS, локальные шрифты и фото,
рабочие формы, редактор закупочных цен.

## Что где лежит

```
dist/                ← ГОТОВЫЙ САЙТ. Содержимое этой папки загружается в корень хостинга.
src/pages/ru|en/     ← тексты страниц (index, about, export, contacts, privacy, 404)
src/templates/       ← шапка, подвал, базовый шаблон, SVG-карты
src/data/site.json   ← телефон, e-mail, адрес, пункты меню, ID Яндекс.Метрики
src/data/prices.json ← закупочные цены (стартовые; на сервере редактируются через /admin/)
src/css/site.css     ← все стили
src/js/              ← site.js (меню, формы, параллакс), prices.js (таблица цен)
static/              ← картинки, шрифты, документы, api/ (PHP), admin/ (редактор цен)
build.py             ← сборка: python3 build.py
```

## Как изменить текст на сайте

1. Откройте нужный файл в `src/pages/ru/` (и парный в `src/pages/en/`), поправьте текст.
2. Телефон, e-mail, адрес, пункты меню — в `src/data/site.json` (меняются сразу на всех страницах).
3. Запустите сборку: `python3 build.py` (нужен Python 3 и `pip install jinja2 pillow`).
4. Загрузите содержимое `dist/` на хостинг. **Не перезаписывайте на сервере `data/prices.json`
   и `api/config.php`** — там живут актуальные цены и пароль.

## Главная: квиз или таблица цен

На главной по умолчанию стоит квиз «Продать зерно за 5 вопросов» (культуры → объём → качество с полями и
вложением протокола → регион → срок отгрузки → телефон). Заявка уходит на trade@tdzz.ru с вложениями,
в Telegram (если настроен) и в журнал `data/leads/`; файлы — в `data/uploads/` (закрыты от доступа снаружи).

* В `/admin/` → «Главная страница» три режима: квиз, «Оцените партию за 60 секунд» (ползунки качества
  по культурам, градация, ближайшие площадки, запрос цены после 4 шага) и таблица цен.
* Пороги и параметры ползунков по культурам — `src/data/passport.json` (пшеница, ячмень, кукуруза,
  подсолнечник, рапс, горох/нут, лён/сафлор), тексты RU/EN там же.
* Тексты вопросов, варианты объёма, регионы, менеджер в сайдбаре — `src/data/quiz.json` (RU/EN), затем `python3 build.py`.
* Кнопки WhatsApp / Telegram на финальном экране появляются, когда в `src/data/site.json` заполнены
  `whatsapp` (номер, например 79270000000) и/или `telegram` (@username).
* Бейдж «Сегодня уже N заявок» считается автоматически по журналу (`api/stats.php`).

## Как менять цены (без программиста)

Откройте `https://tdzz.ru/admin/`, введите пароль (задаётся в `api/config.php`), нажмите
«Загрузить с сайта». Редактируются:

* карточка «Закупаем сегодня» на первом экране (3 строки: название, подпись, цена);
* таблица цен по культурам × элеваторам (пустая ячейка = «По согласованию»);
* названия качеств и требования к ним (клик по названию строки), список элеваторов;
* дата прайса, ставка НДС.

Кнопка «Сохранить на сайт» записывает `data/prices.json`; сайт подхватывает файл сразу.
Перед каждой записью создаётся резервная копия в `data/backups/`.
Если сервер недоступен — «Скачать prices.json» и залить файл по FTP в папку `data/`.

## Установка на хостинг (один раз)

1. Загрузить содержимое `dist/` в корень сайта (нужен PHP ≥ 7.4, обычно есть у любого хостинга).
2. В `api/config.php` задать: `admin_password` (пароль редактора), `mail_to` (куда слать заявки),
   `mail_from` (адрес на домене tdzz.ru — иначе письма уйдут в спам).
   По желанию — токен Telegram-бота, тогда заявки будут приходить и в Telegram.
3. Дать папке `data/` права на запись (обычно 755/775 достаточно; если «Сохранить» выдаёт ошибку — 777).
4. Проверить форму: отправить тестовую заявку с сайта. Все заявки дополнительно пишутся в `data/leads/ГГГГ-ММ.log`.
5. Яндекс.Метрика: вписать номер счётчика в `src/data/site.json` → `metrika_id`, пересобрать.

Подробнее — в `DEPLOY.md`.

## Что изменилось относительно v18

* Один базовый шаблон + partials вместо 12 копий шапки/подвала; RU/EN собираются из общих данных.
* Один `site.css` (≈160 КБ) вместо 13 инлайн-блоков + 3 файлов; `!important` сокращён с 1041 до ~250,
  удалено ~330 неиспользуемых правил. Вёрстка проверена попиксельно на всех страницах.
* Шрифты Golos Text / PT Serif — локально (без Google Fonts), фото продукции — локально (без Pexels).
* Картинки: `loading="lazy"`, `srcset` (480/800/1200/1600) для больших фото; PDF ужат с 5,8 до 4 МБ.
* Формы отправляются на `api/form.php` (письмо + Telegram + журнал), защита: honeypot, время заполнения,
  лимит по IP. Никаких `mailto:`. Маршрутизация писем (`api/config.php` → `mail_routes`):
  квиз и форма «Продать зерно» → trade@tdzz.ru, форма «Экспорт» и тема «Экспортный запрос» → export@tdzz.ru,
  темы «Элеватор / логистика» → logistics@tdzz.ru, всё остальное → info@tdzz.ru. Отделы выведены на странице «Контакты».
* Цены — из `data/prices.json`, редактор в `/admin/`. Демо-генерация цен и «спрятанные» цифры под
  «По согласованию» убраны.
* Подпись «Торговый дом» под логотипом — текстом, шрифт Montserrat как в фирменном логотипе; в шапке чёрная, в подвале белая.
* Мобильная версия прайса: компактная таблица — качество зафиксировано слева, 3–4 колонки и 4 строки в окне, прокрутка в обе стороны.
* schema.org Organization, og-теги, sitemap с hreflang, robots, .htaccess (сжатие, кэш, 404).
